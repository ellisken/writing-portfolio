Create and query an Iceberg table in Lakehouse using the Google Cloud CLI

Quickstart

A quickstart tutorial that demonstrates how borderless Lakehouse lets you share Apache Iceberg tables between open-source engines and Google Cloud. Users create a catalog, create an Iceberg table with Spark via Managed Service for Apache Spark, and query the table in BigQuery using 4-part P.C.N.T syntax with no ETL or manual registration. I authored and tested 100% of this quickstart, adapting existing temporary code labs into a highly reproducible, easy-to-follow tutorial.

Audience: data engineers, data scientists

Sources

  • Existing temporary code labs, adapted into a reproducible tutorial format
  • Hands-on use of the products (Google Cloud CLI, Managed Service for Apache Spark, BigQuery)
